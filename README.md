# Greatlife 🌱

Fast-food bio sans culpabilité — Conakry, Guinée.

Site vitrine + panneau admin pour restaurant Greatlife.

## Stack

- **Frontend** : React 18 + TypeScript + Vite
- **UI** : Tailwind CSS + Framer Motion + shadcn/ui
- **Backend** : Supabase (PostgreSQL + Auth + Storage + Edge Functions)
- **Déploiement** : Vercel

## Démarrage

\`\`\`bash
npm install
cp .env.example .env  # remplir les clés Supabase
npm run dev
\`\`\`
